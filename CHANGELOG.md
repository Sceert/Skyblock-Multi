# Changelog

Este archivo contiene únicamente cambios de versiones publicadas. Las revisiones
internas de prueba se documentan por separado y no forman parte del changelog
público.

## 0.2.4-beta — Minecraft 26.3

- Compatibilidad con Minecraft 26.3, Fabric y Java 25; dependencias actualizadas.
- Interfaz nativa, configuración ampliada, islas radiales hasta 128 posiciones e integración con Nexus Parties.
- Recetas configurables, addons de árboles y materiales de recompensas persistentes.
- Adaptación de entrada SDL, avances, estructuras y registros recargables de recetas.
- Verificados arranque conjunto, 11 árboles BOP, 84 recetas BOP y persistencia tras reinicio.
- Continúa en beta: multijugador real OpenPAC/Xaero y marcas sobre otro jugador pendientes; persiste el fallo conocido de agua entrando al Nexo.

## 0.2.3-beta

- Añadidos los Desafíos Infernales y su API para datapacks.
- Añadidos nuevos contenidos y recursos para la progresión Skyblock.
- Mejoradas las protecciones, la configuración y la compatibilidad multijugador.
- Corregidos diversos errores de generación, interfaz y persistencia.
