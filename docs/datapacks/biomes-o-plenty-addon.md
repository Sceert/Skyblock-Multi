# Biomes O' Plenty addon

El complemento se mantiene como proyecto independiente en `E:\GitHub\SM Addon BOP`.
Sus recursos, recetas, generador y ejemplo de datapack se trasladaron allí.
Compila su JAR con el Gradle Wrapper de ese proyecto e instálalo junto al mod
principal. Skyblock Multi conserva su API genérica de árboles sin depender de BOP.
